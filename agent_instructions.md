# CareerLens — Agent Instructions

## Project Purpose
CareerLens is a career skill-gap and job-readiness analyzer built on the O*NET occupational database.
It uses ML to predict the most suitable career zone and top matching occupations for a given skill profile.

## Architecture

### Data Pipeline (train_model.py)
- Reads O*NET CSV files from `data/`
- Joins: occupation_data → job_zones → career_interest_types → essential_skills → abilities → knowledge → work_styles
- Builds a 44-feature wide matrix per occupation (878 occupations after inner joins)
- Trains 3 classifiers for Job Zone prediction, selects the best by test accuracy
- Fits a KNN NearestNeighbors recommender (cosine similarity, k=10) on all 878 occupation profiles
- Saves full artifact dict to `models/model.pkl`

### Streamlit App (app.py)
- Loads model artifact from `models/model.pkl` at startup (cached)
- User rates 44 features across 5 tabs: Career Interests / Essential Skills / Abilities / Knowledge / Work Styles
- On "Analyze" click:
  1. Builds user feature vector
  2. Predicts Job Zone (1–5) with probability distribution
  3. Finds top-5 matching occupations via KNN cosine similarity
  4. Computes skill-match and skill-gap for top occupation
  5. Produces prioritized "What Should I Learn Next?" list

## Key Files
- `data/` — O*NET CSV files (do not modify)
- `train_model.py` — training pipeline (re-run if data changes)
- `app.py` — Streamlit UI
- `models/model.pkl` — saved model artifact (generated by train_model.py)
- `requirements.txt` — Python dependencies

## Feature Engineering Notes
- RIASEC interests: 6 features from `career_interest_types.csv` (Scale ID = "OI")
- Skills: top 10 by variance from `essential_skills.csv` (Scale ID = "IM")
- Abilities: top 10 by variance from `abilities.csv` (Scale ID = "IM")
- Knowledge: top 10 by variance from `knowledge.csv` (Scale ID = "IM")
- Work Styles: top 8 by variance from `work_styles.csv` (Scale ID = "WI")
- NaN values filled with column median before training and inference

## Extending the App
- Add more features by increasing `top_n_cols()` limits in `train_model.py`
- Add more occupations by relaxing the inner-join chain to left-joins
- Add LLM-powered career advice: use `OPENAI_API_KEY` from `.env`
